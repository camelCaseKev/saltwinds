# saltwinds
Saltwinds is a 2D, top-down naval combat adventure created in the Unity game engine. As captain of a pirate ship, the player’s main objective is to sink merchant vessels to commandeer cargo and obtain gold.
But this is no easy task. Fearsome forts guard trade routes, merchants bear teeth of their own, and fearless pirate hunters stalk the tides.
A pirate's life among the saltwinds is fraught with danger.  

*Initially created as a capstone project for Lake Superior College's CIS Capstone course.

***PLATFORM:*** Windows   
***ENGINE:*** Unity
***SCRIPTING LANGUAGE:*** C#
